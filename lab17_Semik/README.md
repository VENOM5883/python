# Лабораторная работа №17 — Telegram-бот на aiogram 3. Вариант 15 «Медицинская клиника»

Сущности (SQLite): пациент, врач, приём, диагноз — 24 учебные записи (данные вымышленные).
Функции: список врачей, запись на приём, просмотр записей, история посещений, поиск врача.

```
pip install -r requirements.txt
cp .env.example .env        # BOT_TOKEN от @BotFather, ADMIN_IDS
python bot.py               # запуск бота (polling)
python simulator.py         # имитация диалога без сети и токена (для проверки и скриншотов)
pytest                      # 15 тестов
```

| Требование | Реализация |
|---|---|
| Команды | `/start`, `/help`, `/cancel`, `/doctors`, `/book`, `/my`, `/history`, `/find`, `/stats` (админ) |
| Главное меню | Reply Keyboard: Врачи, Записаться, Мои записи, История, Поиск, Помощь |
| Inline + Callback | специальности, врачи, время, подтверждение, действия с записью (`CallbackData` с id) |
| FSM | `Booking`: специальность → врач → дата → время → жалобы → подтверждение (6 состояний); `Registration`, `EditComplaint`, `SearchDoctor` |
| Валидация | ФИО, телефон, дата (формат/прошлое/воскресенье/60 дней), занятое время, короткие жалобы, не-текст, ввод вместо кнопки |
| CRUD | создание записи, просмотр, изменение жалоб, отмена, удаление из истории |
| Middleware | `LoggingMiddleware`: журнал действий и время обработки |
| Архитектура | `handlers` → `services` → `database/repository` → SQLite; `keyboards`, `states`, `middlewares` |
| Асинхронность | обработчики `async`; обращения к SQLite через `asyncio.to_thread`, чтобы не блокировать event loop |
